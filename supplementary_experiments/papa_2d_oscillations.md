# Oscillations in PAPA 2d experiments

Related scripts:
- `papa_2d_nonconverged.py`: Runs the PAPA 2d experiments for starting dates where SWR did not terminate after 30 iterations, stores output from each iteration.
- `plot_papa_2d_oscillations.ipynb` produces plots showing 10m Temperature in iterations 20-40 for these experiments.

The plots are provided in this folder.
